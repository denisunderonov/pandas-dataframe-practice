# Pandas DataFrame Practice

Учебный проект по работе с данными в **Pandas** в рамках School 21.

В проекте на практике разобраны основные операции обработки и анализа табличных данных: загрузка, очистка, преобразование, агрегация, объединение и оптимизация DataFrame.

## Что было сделано

* загрузка и сохранение данных в CSV и JSON;
* работа с датами и временными интервалами;
* фильтрация и сортировка данных;
* обработка пропущенных значений и дубликатов;
* создание и преобразование столбцов;
* группировка и агрегации;
* `merge`, `join`, `concat`;
* pivot tables;
* обогащение данных внешними источниками;
* сравнение способов обработки DataFrame по скорости;
* оптимизация типов данных и использования памяти.

## Стек

* Python
* Pandas
* NumPy
* Jupyter Notebook

## Цель

Закрепить практические навыки работы с Pandas и научиться применять его для подготовки и первичного анализа данных.
